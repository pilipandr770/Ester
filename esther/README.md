# Эстер

Веб-приложение для родителей-эмигрантов: читает выбранные WhatsApp-группы (сад, школа), переводит на русский, делает вечерний разбор и кладёт важные даты в календарь с напоминаниями. Подписка 10 €/мес через Stripe.

## Запуск
1. `cp .env.example .env` и заполнить: `SECRET_KEY`, `DB_PASSWORD`, `EVO_DB_PASSWORD`, `EVOLUTION_API_KEY`, `BASE_URL`, ключи ИИ и Stripe, SMTP (сброс пароля) и данные оператора (`COMPANY_*`, `CONTACT_EMAIL`). При `APP_ENV=production` приложение не стартует с пустым или слабым `SECRET_KEY`/`EVOLUTION_API_KEY` и незаполненными данными оператора.
2. `docker compose up -d --build`. Сервис `migrate` сам применяет миграции схемы (`flask db upgrade`) перед стартом `web` и `worker`.
3. Stripe: создать продукт 10 EUR/мес, `price_...` в `STRIPE_PRICE_ID`; webhook на `BASE_URL/webhook/stripe` (события: `checkout.session.completed`, `customer.subscription.created|updated|deleted`, `invoice.payment_failed`), секрет в `STRIPE_WEBHOOK_SECRET`. Для НДС включите Stripe Tax и `STRIPE_AUTOMATIC_TAX=1`.
4. Поставить reverse proxy (Caddy/nginx) с HTTPS на `127.0.0.1:8000` (порт опубликован только на localhost). Порт Evolution наружу не публиковать. Если перед приложением не один прокси, поправьте `PROXY_HOPS`.

## Разработка
- `APP_ENV=development`, `pip install -r requirements.txt -r requirements-dev.txt`, `python -m pytest tests`.
- Изменили `models.py`: `flask db migrate -m "..."`, проверьте файл в `migrations/versions/`, затем `flask db upgrade` (`FLASK_APP=app.py`). Для БД, созданной старой версией через `create_all`, проще пересоздать её; рабочих данных до запуска нет.
- Лимиты попыток входа считаются в памяти каждого воркера gunicorn; для точных лимитов задайте `RATELIMIT_STORAGE_URI=redis://...`.

## Архитектура
- `app.py` Flask: регистрация, вход и сброс пароля (CSRF, лимиты), QR, выбор чатов, лента, календарь + ICS, Stripe, `/health`
- `evolution.py` клиент Evolution API, на пользователя свой инстанс
- `pipeline.py` вебхук только ставит сообщения выбранных групп в очередь (таблица `webhook_job`, без вызовов ИИ, ответ мгновенный); воркер обрабатывает их (перевод, OCR, голосовые) с повторами по нарастающей паузе, на последней попытке сохраняет сообщение без перевода. Дневные лимиты на сообщения и медиа, лимит размера файлов и числа чатов (`MAX_*` в `.env`). Вечерний разбор, напоминания
- `ai.py` перевод + автоопределение языка (Claude), OCR фото (Claude vision), голосовые (Whisper), разбор дня; большие чаты режутся на куски, при обрезанном JSON запрос делится пополам
- `worker.py` каждые 5 секунд очередь сообщений; раз в минуту вечерний разбор не раньше заданного времени (один раз в сутки, повтор при сбое ИИ в течение 3 часов), напоминания в WhatsApp (без указанного номера не помечаются отправленными, при сбое отправки повторяются) и письмо, если WhatsApp отключился
- Приватность: `/account/export` выгружает данные пользователя в JSON, ссылку календаря можно перевыпустить, Sentry (`SENTRY_DSN`) не получает тела запросов и локальные переменные
- CI: `.github/workflows/ci.yml` (рабочая папка `esther`) гоняет тесты и проверяет, что миграции совпадают с моделями
- `billing.py` Stripe: статус берётся из самой подписки, события идемпотентны; при удалении аккаунта подписка отменяется
- `config.py` настройки и проверка конфигурации при старте, `mailer.py` SMTP

## Важно перед запуском для клиентов
- Evolution (Baileys) это неофициальный API: WhatsApp может банить номера. Ставьте `readMessages=false` (уже стоит), не рассылайте ничего, кроме напоминаний самому пользователю.
- Приватность: сообщения групп содержат данные чужих детей и родителей. Нужны Datenschutzerklärung, AVV с Anthropic/OpenAI, предупреждение пользователю. Очистка уже есть: `worker.py` ежедневно в 03:15 UTC удаляет сообщения старше `RETENTION_DAYS` (по умолчанию 30); события и разборы остаются, пока жив аккаунт (так же написано в политике).
- Протестируйте разбор на реальных еврейских чатах: относительные даты («в четверг») и RTL-текст.
